# Fixture - Vague billing recovery request

We need to improve what happens when customers do not pay on time.

Maybe the product should:
- send reminders automatically
- block access after some time
- notify the account owner
- maybe give admins a manual action too

It should feel simple and maybe mostly automatic.

Not sure yet:
- who decides when the customer is blocked
- whether this is based on invoice age, subscription state, or both
- whether blocking should be partial or full
- whether reminders are emails, in-app notifications, or both
- whether the action applies to all workspaces or only some plans

We just need the feature spec so implementation can start.
