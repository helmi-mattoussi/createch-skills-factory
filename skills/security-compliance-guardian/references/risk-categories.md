# Risk Categories

Review the delivery unit against these categories when relevant.

## RC-001 Authentication
- login, session, identity proof, credential handling

## RC-002 Authorization
- role checks, ownership checks, server-side enforcement, denial behavior

## RC-003 Sensitive data exposure
- PII, billing data, private files, logs, exports, debug output

## RC-004 Destructive or irreversible actions
- delete, archive, revoke, publish, send, restore-sensitive flows

## RC-005 File and media access
- upload, download, signed URLs, storage boundaries, unauthorized retrieval

## RC-006 External trust boundaries
- webhooks, third-party APIs, background workers, transport boundaries
