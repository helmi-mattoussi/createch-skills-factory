# Backward Propagation

Route upstream when:

- validated behavior implies a background or integration concern that architecture never addressed
- runtime recovery expectations require a missing product or architecture decision
- the reviewed unit exposes a gap that should be fixed in `.feature`, `PD-*`, or module architecture rather than only patched operationally

Typical return paths:
- `module-architecture-advisor` for missing runtime structure
- `sdd-spec-writer` if the intended failure behavior is under-specified
- `brief-to-product-docs` if the product expectation itself is unclear
