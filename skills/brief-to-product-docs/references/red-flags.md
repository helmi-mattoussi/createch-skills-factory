# Red Flags

Stop scope drift when the request starts asking for:
- `.feature` scenarios
- acceptance criteria written as executable behavior
- architecture decomposition
- API or schema design
- screen inventory or detailed UX flows
- backlog breakdown into stories or tasks as primary output

Typical misroutes:
- "write the feature already"
- "decide the architecture while you frame"
- "define the screens and forms"
- "split it into stories and tasks"
