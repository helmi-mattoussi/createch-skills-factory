# Decision Matrix

Choose the output depth using this logic.

## Produce a full Product Framing Dossier when
- business objective is identifiable
- problem is identifiable
- main actors are identifiable
- first-level scope is mostly stable
- uncertainty can be made explicit without breaking the dossier

## Produce a partial dossier when
- intent is recoverable
- some key sections are still incomplete
- a grounded subset is still useful for review

## Stop and say the task is too immature when
- the main objective cannot be inferred safely
- several strategic interpretations compete with no preference
- the request is really broad discovery, architecture, or UX work
