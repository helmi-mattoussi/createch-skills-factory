# Decision Matrix

## `READY FOR RELEASE`

Use when:
- quality review passed
- security review passed or was not materially required
- no unresolved blocking item remains
- rollout shape is low-risk or clearly manageable

## `READY FOR RELEASE WITH WATCH ITEMS`

Use when:
- no blocker remains
- some monitored follow-ups still matter after release
- rollout needs explicit watch items, flag control, or sequencing care

## `HOLD`

Use when:
- a required upstream review is missing
- any blocking item remains unresolved
- rollout depends on migration, rollback, or environment assumptions that are not yet credible
