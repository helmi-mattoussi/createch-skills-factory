# Final Review Checklist

- Is the reviewed scope explicit?
- Were validated `.feature` files actually consulted?
- Were applicable `PD-*` and `ADR-*` checked?
- Is behavior conformity judged against sources rather than code convenience?
- Are permission checks explicitly reviewed?
- Is there credible evidence for the main scenarios?
- Are blockers distinguished from non-blocking follow-ups?
- Are lateral concerns escalated instead of absorbed?
- Is backward propagation recommended where upstream truth is wrong?
- Would release planning still need to reconstruct review conclusions?
