# Security and Publication Scope

This repository is a public portfolio artifact. It must not contain client data, credentials, private URLs, local environment files, production configuration, or application source code from client work.

## Reporting a concern

If you identify information that should not be public, do not open a public issue containing the sensitive content. Contact the repository owner through the contact details shown on the associated portfolio profile and describe the file path and nature of the concern.

## Intended use

The skills are published for technical evaluation and portfolio review only. They are not production-ready autonomous agents, and they must not be used to make unsupervised product, architecture, security, or release decisions.
